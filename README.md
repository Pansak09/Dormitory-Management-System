# Dormitory Management System

ระบบจัดการหอพักด้วย Django สำหรับดูแลหอพัก ห้องพัก ผู้เช่า บิลค่าเช่า และการชำระเงิน

## ความสามารถหลัก

- จัดการหอพักและห้องพัก: เพิ่ม แก้ไข ลบ และสร้างหลายห้องพร้อมกัน
- ลบหลายห้องหรือทั้งชั้น พร้อมยืนยันก่อนลบ
- แสดงสถานะห้องว่าง/มีผู้เช่า และรายละเอียดผู้เช่า
- บทบาทผู้ใช้ 3 ระดับ: ผู้ใช้ทั่วไป ผู้เช่า และแอดมิน
- ผู้ใช้ส่งคำขอเป็นผู้เช่าจากรายละเอียดห้องได้
- แอดมินเชิญผู้ใช้เป็นผู้เช่าหรืออนุมัติคำขอได้
- เมื่ออนุมัติ ระบบจะผูกบัญชีผู้ใช้เข้ากับห้องและบันทึกข้อมูลผู้เช่าอัตโนมัติ
- บิลค่าเช่ารายเดือน: ค่าห้อง ค่าน้ำ ค่าไฟ ค่าอินเทอร์เน็ต และรายการเพิ่มเติม
- คำนวณค่าน้ำ/ไฟจากหน่วยเริ่มต้นและหน่วยปัจจุบัน
- สถานะบิล: ค้างชำระ → รอตรวจสอบการโอนเงิน → ชำระเงินแล้ว
- ผู้เช่าส่งสลิปโอนเงิน และแอดมินตรวจสอบการชำระเงินได้
- Dashboard สรุปรายรับ ยอดค้างชำระ บิลรอตรวจสอบ ห้องว่าง และผู้เช่า
- สมัครสมาชิกด้วยชื่อผู้ใช้หรือ Google โดย Google ครั้งแรกต้องกรอกข้อมูลผู้เช่าเพิ่มเติม

## เทคโนโลยี

- Python 3 และ Django 5.2
- PostgreSQL
- django-allauth สำหรับการเข้าสู่ระบบด้วย Google
- Tailwind CSS, HTMX และ Chart.js

## การติดตั้ง

1. สร้างและเปิดใช้งาน virtual environment

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. ติดตั้ง dependencies

   ```powershell
   pip install -r requirements.txt
   ```

3. สร้างไฟล์ `.env` ในโฟลเดอร์หลักของโปรเจกต์

   ```env
   SECRET_KEY=your-secret-key
   DEBUG=True
   DB_NAME=dormitory_db
   DB_USER=postgres
   DB_PASSWORD=your-database-password
   DB_HOST=localhost
   DB_PORT=5432

   GOOGLE_CLIENT_ID=your-google-client-id
   GOOGLE_CLIENT_SECRET=your-google-client-secret
   ```

4. สร้างตารางฐานข้อมูล

   ```powershell
   python manage.py migrate
   ```

5. สร้างบัญชีแอดมิน

   ```powershell
   python manage.py createsuperuser
   ```

6. เริ่มระบบ

   ```powershell
   python manage.py runserver
   ```

   เปิด [http://127.0.0.1:8000](http://127.0.0.1:8000) ในเบราว์เซอร์

## ขั้นตอนใช้งานเบื้องต้น

1. แอดมินสร้างหอพักและเพิ่มห้อง
2. ผู้ใช้สมัครสมาชิก พร้อมชื่อ เบอร์โทร และที่อยู่
3. ผู้ใช้กด **ขอเป็นผู้เช่าห้องนี้** หรือแอดมินส่งคำเชิญ
4. แอดมินอนุมัติคำขอ หรือผู้ใช้ตอบรับคำเชิญ
5. แอดมินสร้างบิลจากเมนู **บิลค่าเช่า**
6. ผู้เช่าส่งสลิป และแอดมินยืนยันการชำระเงิน

## คำสั่งที่ใช้บ่อย

```powershell
# ตรวจสอบปัญหาการตั้งค่า
python manage.py check

# สร้าง migration หลังแก้ไข model
python manage.py makemigrations

# อัปเดตฐานข้อมูล
python manage.py migrate
```

## โครงสร้างโปรเจกต์

```text
accounts/            บัญชีผู้ใช้ โปรไฟล์ผู้เช่า และการเข้าสู่ระบบ
billing/             บิลค่าเช่า รายการค่าใช้จ่าย และสลิปโอนเงิน
dorms/               ข้อมูลหอพักและ Dashboard
rooms/               ห้องพักและการจัดการห้องแบบหลายรายการ
tenancy/              คำขอและคำเชิญผู้เช่า
templates/            หน้าจอ HTML
```

## หมายเหตุด้านความปลอดภัย

- ห้าม commit ไฟล์ `.env` หรือรหัสผ่านฐานข้อมูลขึ้น Git
- ตั้งค่า `DEBUG=False` และใช้ `SECRET_KEY` ที่ปลอดภัยก่อนนำขึ้นใช้งานจริง
- จำกัด `ALLOWED_HOSTS` ให้เป็นโดเมนที่ใช้งานจริง
